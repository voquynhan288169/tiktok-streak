Giữ chuỗi TikTok

Mọi thứ chạy trong GitHub của bạn. Trang này chỉ gọi GitHub từ trình duyệt của bạn và không lưu gì ở nơi khác.

1. Kết nối GitHub

Tạo token thế nào?

GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token. Chọn Only select repositories và chỉ chọn repo này. Cấp quyền Actions, Secrets, Contents đều ở mức Read and write. Token chỉ tồn tại trong tab này, đóng tab là mất.

2. Tài khoản TikTok

Lấy sessionid ở đâu?

Đăng nhập tiktok.com trên máy tính, nhấn F12 → Application → Cookies → tiktok.com, copy cột Value của dòng sessionid. Cookie được mã hóa ngay trong trình duyệt rồi mới gửi lên GitHub Secrets, không ai đọc lại được, kể cả bạn.
